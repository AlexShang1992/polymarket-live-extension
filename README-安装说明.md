# BTC 5分钟 · 本机行情对照

这是一个独立的 Chrome Manifest V3 插件。它在 Polymarket 的 BTC 5分钟市场价格区旁，显示本机采集的 BTC 当前价及相对本轮目标价的涨跌金额。涨跌金额加大显示，绿色上涨、红色下跌。官网原有价格保留，便于对照。

## 第一次安装

可以先双击 **安装插件.command**，它会打开 Chrome 安装页面和本文件夹，再按下列步骤加载。Chrome 本地插件需要手动加载一次，此入口不会修改浏览器配置或自动连接钱包。

1. 先启动之前的本机行情页面：双击相邻 `btc5m-live` 文件夹里的 **打开页面.command**。关闭行情网页后本机服务仍可继续工作。
2. 在 Chrome 地址栏输入 `chrome://extensions/`，打开右上角 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择本文件夹 `polymarket-live-extension`，其中包含 `manifest.json`。不要选择上一级 outputs。
4. 刷新 Polymarket 的 BTC 5分钟市场页面。中文、英文及站内切换均支持。

当前市场网址每5分钟变化。插件会检查网址轮次和本机数据轮次；旧页面、未来页面或轮次不一致时，不会显示另一轮的价格，而会提示并提供“打开当前轮”链接。它不会强制把官网跳转到下一轮，也不会改变官网交易页面的行为。

## 连接与数据

- 数据来自已有本机服务的 `http://127.0.0.1:8765/events`，通过推送更新，不另外按秒轮询官网。不需要打开单独的行情标签页，但服务需要运行。
- 点击 Chrome 工具栏中的插件图标，可查看连接情况。若本机服务改用了其他端口，在弹出页填写端口，保存并重连。
- 使用原来相同的 Chainlink 60秒 TWAP 价格口径；接口实际约每秒一个 BTC 价格点，不保证比官网快。
- 断线或价格过期时保留同轮最后数值、降低亮度并标注状态，自动重连。换轮时不混用旧目标价或上一轮价格。
- 官网布局变化后，插件可能需要更新定位规则。

## 权限与删除

仅申请在 Polymarket 网站插入显示块、读取本机回环地址的行情、保存一个本机端口设置的权限。没有钱包、私钥、账户、Cookie 或交易接口权限；不发送交易，不采集登录信息，不向外上传数据。

不要直接删除仍在加载使用的插件目录。先到 `chrome://extensions/` 移除此插件，再删除整个 `polymarket-live-extension` 文件夹即可。不会删除或停止原有行情服务、模拟交易项目。

## 开发验证

`node --test test_protocol.mjs` 验证字段投影、空值、消息顺序、重启和分块推送解析。浏览器验证记录见 `验收记录.md`。

1.0.1 布局调整：本机数据贴在官网当前价格右侧，透明背景、无悬浮卡片，随原价格滚动；右侧空间不足时放在原价格下方。更新文件后，在 Chrome 扩展程序页面点击本插件的“重新加载”，再刷新 Polymarket 页面。

1.3.4 曲线功能：官网原曲线上方新增本机 BTC 实时曲线，页签顺序为“Up·Down / 15 分钟 / 5 分钟 / 60 秒”。打开或切换到新的 BTC 5分钟页面时，默认进入 Up/Down。

- 三档均为滚动时间范围；15分钟数据从本机服务启动后逐步积累，最多保留最近15分钟真实数据。
- 复用本机服务已经采集到的本轮历史点，打开插件即可回填；没有采集到的区间留空，断线超过5秒的缺口不连线。
- 橙线为 BTC 价格，虚线只标示当前轮对应时段的目标价；目标金额始终保留在图表下方。
- Up/Down 页签只显示最近60秒：绿色 Up、红色 Down 和橙色 BTC 使用完全相同的60秒时间轴，便于直接比较同一时刻的变化。曲线左侧会直接标出 Up/Down；橙色 BTC 使用左侧独立美元刻度，Up/Down 使用右侧美分刻度。
- 鼠标移到曲线上可查看对应时间及金额，也支持点击和左右方向键查看。
- 旧轮次页面不展示新轮次曲线，连接过期时保留同轮曲线并标注。
- 更新后到 Chrome 扩展管理页面点击本插件的“重新加载”，再刷新官网，无需重新安装。

1.3.4 时间轴调整：Up/Down 为默认第一个页签，绿色、红色和橙色三条曲线统一显示最近60秒并共用时间轴；官网原生价格不变。

1.3.5 显示优化：三条线改为不超出真实数据范围的平滑曲线。只改变连线的视觉效果，不平均、不改写价格数据，断线缺口仍保留。

1.3.5 显示优化：Up/Down 为默认第一个页签，三条平滑曲线统一显示最近60秒并共用时间轴；官网原生价格不变。

当前版本 **1.3.6**：Up/Down 页签的顶部数值行在 BTC 当前价后追加当前价相对本轮目标价的差额；高于目标价显示绿色 `↑ $金额`，低于目标价显示红色 `↓ $金额`。
